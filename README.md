# Administrative Data Management

This project demonstrates practical administrative and data management skills, including data entry, data organisation, data cleaning, record management, and reporting.

## Project Overview

The project uses a fictional customer dataset to demonstrate how administrative information can be captured, organised, maintained, and prepared for reporting.

## Skills Demonstrated

* Data entry and organisation
* Customer record management
* Data cleaning
* Spreadsheet/data handling
* Sorting and filtering data
* Identifying customer status and priority
* Basic reporting
* Attention to detail

## Dataset

The `data/customer_records.csv` file contains 5 fictional customer records with the following fields:

* Customer ID
* Customer Name
* Email
* Department
* Status
* Priority

## Tools Used

* Microsoft Excel
* CSV
* GitHub

This project forms part of my professional portfolio and demonstrates my ability to work with administrative data accurately and systematically.

# Project Notes

## Project Objective

The objective of this project is to demonstrate practical administrative data management skills using a fictional customer dataset.

## Process

1. Created a customer dataset using fictional information.
2. Organised the information into structured columns.
3. Reviewed the records for consistency.
4. Created a cleaned version of the dataset.
5. Summarised the information by status, priority, and department.
6. Created a basic customer summary report.

## Skills Applied

* Data entry
* Data organisation
* Data cleaning
* Record management
* Data summarisation
* Basic reporting
* Attention to detail
* GitHub file management

## Tools

* CSV
* Markdown
* GitHub
* Microsoft Excel
